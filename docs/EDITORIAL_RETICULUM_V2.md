# Compression & Consolidation — executable editorial reticulum v2

This profile strengthens the existing Juriscribe C&C pipeline without replacing it. The v0.12 structural proof remains the base invariant. The v2 layer adds executable editorial structure, causal transformation authorization, split-capable semantic binding and seeded falsification evidence.

## Proof chain

`source inventory → source semantic reticulum → editorial-function reticulum → refactoring-surgery reticulum → seeded mutation evidence → refined projection → structural proof → editorial refinement proof → review/provenance/final review → atomic artifacts`

The runtime can emit `A_LEVEL_EDITORIAL_READY` only for the bounded editorial/argument/compression properties it recomputes. This status is not a claim of scientific truth, legal entailment, peer review or journal acceptance.

## Minimality

The layer reuses the existing inventory, gap map, refactoring contract, 10M mutation receipt, saturation, calibration, proof-carrying semantics, review and artifact pipelines. It adds no new user-facing mode and no independent second C&C implementation.

`SPLIT` now keeps the original semantic-unit id and may bind it to multiple output objects. Non-split projections continue through v1 structural proof behavior. Merge and reorder remain legal operations only when the current plan explicitly authorizes the affected units.

## Falsification profile

The seeded campaign exercises semantic loss/new-unit injection, relation rewiring, false witnesses, unknown output objects, unbound gaps, unjustified operations, unauthorized reorder/merge/split, compression/expansion bounds, duplicate output, stale proof binding, material human recalibration, divergent repeats, idempotent repeats, Unicode/layout edges and long-form scale.

A compliant receipt requires at least 10,000,000 instances, at least eight distinct seeds, all required scenario families, at least 1,000 full reticulum/proof deep checks, zero survivors and zero oracle mismatches. CI runs two 10M campaigns with independently shifted seed spaces. Instance counts are soak volume and never represented as unique semantic texts.
