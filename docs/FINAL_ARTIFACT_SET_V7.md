# Final artifact set v0.7

Una sessione `COMPLETE` deve materializzare almeno sei ruoli, tutti con readback `PASS` quando la capability host esiste:

1. `final_chapter` — testo consegnabile;
2. `evidence_dossier` — mappa claim/inferenza → evidenza → locator finale;
3. `source_register` — fonti effettivamente usate, perimetro, verifica e pinpoint;
4. `inference_register` — inferenze materiali esplicite con premesse, ponte, falsificatore e disposizione;
5. `transformation_ledger` — review, rigenerazioni, compressione e trasformazioni materiali;
6. `session_dashboard` — fascicolo umano di stato e controllo.

Il provenance bundle è la fonte strutturata che collega questi artefatti. Nessun artefatto deve pretendere di rappresentare chain-of-thought latente: registra soltanto oggetti epistemici e trasformazioni esplicitamente materializzati durante la sessione.
