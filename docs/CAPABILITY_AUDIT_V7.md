# Capability audit v0.7

## Benchmark osservato

Il benchmark cieco su Henry Sumner Maine, *Ancient Law*, ha mostrato che Juriscribe v0.6 può produrre una continuazione concettualmente robusta ma scientificamente non consegnabile se generalizzazioni storico-giuridiche e inferenze nate nella sessione non vengono trasformate in provenance esplicita.

## Hardening v0.7

| Capacità | v0.6 | v0.7 | Limite residuo |
|---|---|---|---|
| Bootstrap AI web/connector | parziale | T&C → probe receipt → initialize → ACTIVE visibili e fail-closed | non è un ACL server-side |
| Scelte chat | ad hoc | interaction card digestate + sempre `ALTRO` | qualità della formulazione resta host-dependent |
| Provenance inferenze | claim/ledger parziale | disposition lossless per oggetti materiali registrati | non osserva ragionamento latente |
| Final review | review post-bozza + quality | review aggiuntiva candidato/corpus/provenance/normative-frame bound | non sostituisce referee umano |
| Artefatti | capitolo/dashboard/readback | sei ruoli minimi + readback | formati dipendono dalle capability host |
| Dashboard | dossier tecnico-editoriale | progressive disclosure human-first | accessibilità va testata su casi reali |

## Mutation evidence

10.000 mutazioni v0.7, dieci famiglie: bootstrap non ACTIVE, probe stale/tampered, interaction senza free path, provenance incompleta/stale, final review stale/aperta e set artefatti incompleto. Baseline attesa: 10.000 killed, 0 escape, 1.000 controlli accettati, 0 falsi positivi.
