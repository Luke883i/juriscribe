# Juriscribe session model v0.9

Una sessione lega: request, bootstrap, mode selection, mode contract, editorial standard, corpus/concept/review target, reticolo, setup, DoD, fonti/claim/inferenze, eventuale generation/continuation contract, drafts o review target, review, provenance, final review, artifact registry e completion evidence.

`session.integrity.json` è il manifest canonico. Il suo digest non contiene corpus text né chain-of-thought.

La modalità è immutabile dopo l'ingestione sostanziale; per cambiare tipo di lavoro si apre una nuova sessione o si resetta prima del corpus.
